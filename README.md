# Aya Almalla Portfolio — v5

Static personal portfolio built with HTML, CSS, and vanilla JavaScript.

## v5 updates
- Replaced the hero illustration with a cleaned transparent high-resolution AI network asset.
- Added subtle continuous rotation, hover acceleration, pointer parallax, and click pulse interaction.

- Preserved the existing cream / turquoise / orange visual identity and teal contact block.

- Respects `prefers-reduced-motion` for accessibility.

## Deploy on GitHub Pages
Upload the contents of this folder to the root of your repository, then enable:

**Settings → Pages → Deploy from a branch → main → /(root)**
